# Как использовать
1) Положить скрипт в папку с распакованным архивом и Excel-таблицей
2) Установить библиотеки (если не установлены):

```bash
pip install pandas openpyxl pyyaml
```
3) Изменить настройки в начале файла (пути к папкам, имя Excel-файла)
4) Запустить скрипт:

```bash
python pipeline.py
```
Протокол встречи Kickoff методологии автоматизации сборки тестовых корзин.
Тема: автоматизация сборки кейсов БКАС
Участники: Пухаев Георгий, Кандакова Виктория, Василевская Наталья, Терешкин Сергей, Манько Андрей
1.Что показано
1.1. Скрипт сборки кейса. 
1.2. Задание для агента порождается из того же файла, по которому работают проверки, поэтому скрытых требований в кейсе не возникает. Ранее кейсы возвращались именно за это.
1.3. Общая библиотека сопоставления ответа с контрактом, одна на все кейсы вместо самописной проверки в каждом. Учитывает привязку и к функции, и к месту вызова, требует объяснения механики дефекта, отсекает отрицания дефекта и сборные записи, закрывающие несколько требований разом.
1.4. Валидатор чужих кейсов, разложенный по семействам замечаний УМР. Прогнан на шести принятых кейсах: находит те же дефекты, что перечислены в рубрике, базовый образ не закреплён дайджестом ни в одном из шести.
1.5. Самопроверка кейса
2. Основное ограничение 
2.1. Уперлись в Docker. Полный прогон кейса сборка образа и получение reward так, как это делает УМР, без него невозможен.

3.2. После получения доступа к стенду  полный прогон сборки и проверки кейса.
